EvidenceRAG

Document Q&A that answers only from retrieved citations, with a guaranteed refusal when evidence is missing and published eval metrics. Citation precision 0.99 on a published golden set.

  • RAG
  • Python
  • LLM Evaluation
Case study

The gap

AI search tools generate an answer first and attach citations after; independent research (Tow Center, 2025) found over 60% of AI search answers were wrong or unsupported, and fabricated citations are common. A citation you cannot trace is decoration.

What it does

Answers questions over a document corpus only from retrieved citations. If the evidence is not there, it refuses instead of guessing.

What I built

Hybrid dense + BM25 retrieval, cross-encoder re-ranking, extractive answers with document, page, and character-offset citations, a guaranteed insufficient-evidence refusal, and a published golden-set evaluation (citation precision 0.99).

Tech

Python, RAG, cross-encoder re-ranking, Gradio on Hugging Face.

Forkwise

Fork and replay agent runs step by step, diff outcomes, and track cost per successful task.

  • Python
  • FastAPI
  • Agent Observability
Case study

The gap

Agent runs are black boxes. When an output changes, you cannot tell which step caused it, what it cost, or replay just that step.

What it does

Lets you fork any recorded agent run from any step, replay it with recorded tool results, diff the outcome, and see cost per successful task.

What I built

One-decorator instrumentation with typed spans stored in a single SQLite file, fork and replay from step N, side-by-side outcome diffs, cost per successful task with budget ceilings, and one-click export of a trace as a pinned pytest test. The live demo runs real EvidenceRAG questions.

Tech

Python, FastAPI, SQLite, agent observability.

TrustLens

An eval gate for retrieval changes that separates regressions a change caused from pre-existing failures, with a ship or do-not-ship verdict.

  • LLM Evaluation
  • Python
  • RAG
Case study

The gap

Teams change chunking, models, or re-ranking and then guess whether retrieval got better. A single pass-rate number hides what actually broke.

What it does

Compares two versions of a retrieval system on a golden set and returns a ship or do-not-ship verdict.

What I built

Failure classification into five categories (pass, right source wrong sentence, wrong source, answered but should refuse, refused but should answer), a verdict that separates regressions a change caused from pre-existing failures, case-by-case version A vs B diffs, and per-case latency.

Tech

Python, LLM evaluation, RAG.
